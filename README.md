# Dev Notes & Snippets

A personal collection of learning notes, code snippets, bookmarks, and ideas I pick up along the way.

## Structure

```
notes/       — daily learning log
snippets/    — small reusable code snippets
resources.md — bookmarked articles and references
TODO.md      — things to explore next
```

## Why this repo?

I find that writing things down — even briefly — helps me retain what I learn.
This is my scratchpad for that.
